
# Patch: توضیح HS + کاوشگر تجارت

این بسته دو تغییر اصلی دارد:

## 1. توضیح کنار کدهای HS
- HS2: کد + عنوان فارسی
- HS8: کد + شرح دقیق dd.xlsx
- HS4 و HS6: چون فایل فعلی عنوان رسمی مستقل ندارد، کد + چند نمونه از شرح زیرتعرفه‌های HS8 با عبارت «شامل: ...» نمایش داده می‌شود.
- همچنین automargin نمودارها فعال شده تا برچسب‌ها بریده نشوند.

اگر بعداً جدول رسمی عنوان HS4/HS6 در اختیار باشد، می‌توان بدون تغییر معماری جایگزین این توضیح نمونه کرد.

## 2. صفحه جدید «کاوشگر تجارت»
فیلتر همزمان:
- صادرات / واردات
- بازه سال
- یک یا چند گمرک
- یک یا چند کشور طرف معامله
- HS2
- HS4
- HS6
- HS8

خروجی:
- ارزش دلاری
- ارزش ریالی
- وزن
- ارزش هر تن
- روند سالانه هر چهار شاخص
- جدول سالانه
- دانلود CSV

نکته: داده کشور دارد، نه شهر. مثلاً دبی جدا از امارات متحده عربی قابل تشخیص نیست.

# نحوه نصب

## الف) فایل‌ها را جایگزین/اضافه کنید

در ریشه Dashboard:
- `app.py` ← جایگزین
- `page_utils.py` ← جایگزین
- `hs_helpers.py` ← جایگزین
- `prepare_explorer_data.py` ← جدید
- `requirements.txt` ← جایگزین

در پوشه pages:
- `trade_explorer.py` ← جدید

صفحات فعلی دیگر را نگه دارید.

## ب) نصب DuckDB
داخل terminal محیط `.venv`:

`pip install duckdb`

یا برای همسان شدن کامل محیط:

`pip install -r requirements.txt`

## ج) ساخت دیتای کاوشگر

`python prepare_explorer_data.py`

این مرحله دوباره export-all.dta و import-all.dta را می‌خواند و ممکن است چند دقیقه طول بکشد.

خروجی‌ها در:
`data/processed/explorer/`

به صورت فایل‌های جداگانه سال/جریان ذخیره می‌شوند تا هیچ فایل Parquet بسیار بزرگی برای GitHub ساخته نشود.

## د) اجرای Streamlit

اگر در حال اجراست:
`Ctrl+C`

سپس:
`streamlit run app.py`

در منوی سمت راست/Sidebar صفحه جدید «کاوشگر تجارت» ظاهر خواهد شد.

## نمونه فیلتر
برای «صادرات یک HS8 از بوشهر به امارات»:
- جریان = صادرات
- گمرک = منطقه ویژه اقتصادی بوشهر
- کشور = امارات متحده عربی
- HS8 = کد مورد نظر

برای «تجارت عمان از مسیر شهید رجایی»:
- اگر ورود کالا از عمان به ایران مدنظر است: جریان = واردات
- گمرک = منطقه ویژه اقتصادی شهید رجایی
- کشور = عمان
