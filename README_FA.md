
# صفحات تکمیلی داشبورد تجارت خارجی

این Patch از همان فایل‌های Parquet که `prepare_data.py` نسخه اول می‌سازد استفاده می‌کند؛
بنابراین بعد از تمام شدن اجرای فعلی، نیازی به اجرای دوباره preprocessing نیست.

## نصب
1. ZIP را Extract کنید.
2. `app.py` را جایگزین `app.py` پروژه کنید.
3. `page_utils.py` را کنار `app.py` کپی کنید.
4. فایل‌های `commodities.py`، `partners.py`، `customs.py` و `bushehr_analysis.py`
   را داخل پوشه `pages` پروژه کپی کنید.
5. فایل `overview.py` قبلی را نگه دارید.
6. اگر Streamlit در حال اجراست، معمولاً خودش Reload می‌شود. اگر نشد:
   `Ctrl+C`
   و سپس:
   `streamlit run app.py`

## صفحات
- کالاها و تعرفه‌ها: رتبه‌بندی HS2، روند، پروفایل کالا، LQ بوشهر
- شرکای تجاری: رتبه‌بندی، تمرکز Top 3/5/10، HHI، روند کشورها، پروفایل کشور
- گمرک‌ها و بنادر: رتبه‌بندی، تمرکز، روند مقایسه‌ای، ارزش در برابر وزن، پروفایل گمرک
- تحلیل بوشهر: سهم ملی، رشد نسبی، ارزش هر تن، تمرکز مقصد/کالا، LQ و ساختار صادرات

## مرحله بعد
صفحه «کاوشگر تجارت» که فیلتر همزمان `گمرک × کشور × HS` داشته باشد به فایل‌های
تجمیعی چندبعدی جدید نیاز دارد. آن را در preprocessing مرحله دوم می‌سازیم.
